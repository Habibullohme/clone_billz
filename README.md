# Do'kon — ulgurji oyoq kiyim do'koni uchun kassa

Billz o'rniga: kassa (skaner, pachkalab sotuv, so'm/dollar/karta/nasiya), mahsulotlar,
shtrix-kodlar, hisobotlar va Telegram bot. Talablar: [docs/TALABLAR.md](docs/TALABLAR.md).

## Ishga tushirish

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # hisob-kitob va skaner testlari
npm run build    # dist/ — Netlify'ga joylanadi
```

Hozircha ma'lumotlar brauzer xotirasida saqlanadi (sinov rejimi, namunaviy tovarlar).
Keyingi bosqich — Supabase (baza + login).
